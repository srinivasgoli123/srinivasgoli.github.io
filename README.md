# Srinivas Goli — Academic Website

Static website (HTML + CSS, no build step) migrated from
https://sites.google.com/view/srinivas-goli/bio

## Pages
- `index.html` — Bio and profile links
- `teaching.html` — Courses and supervision
- `publications.html` — Books, reports, journal articles
- `research-projects.html` — Major and consultancy projects
- `miscellaneous.html` — Advisory roles, editorial activities, awards

## Add your photo
Save your profile picture as `assets/profile.jpg` (square, ~600×600). If the file is missing, the page simply hides the photo.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000

## Deploy (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)`.
